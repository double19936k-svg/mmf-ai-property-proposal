# Demo Run（虚构数据）

这个目录只演示输入长什么样，**不是**真实招标，也不是真实生成结果。

请不要把真实客户的 `runs/` 复制到这里。

## 虚构项目

- 项目名称：示例滨海科技园
- 业态：产业园区
- 场景：完整物业服务方案
- 地点：示例城市滨海新区示例路 100 号（虚构）
- 规模：约 12 万平方米（虚构）

## 用法

1. 启动 MMF。
2. 用「新建方案」，把 `brief.json` 里的字段填进页面。
3. 选择 Mock 引擎可以只验证流程；选择你自己配置的云端引擎才会真正写正文。
4. 生成结果会写到本机 `output/` 与 `runs/`，默认已被 `.gitignore` 排除。
