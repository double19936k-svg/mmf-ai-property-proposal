# MMF Desktop / Local 使用说明

版本：0.1.1-alpha  
状态：初始可部署（不是商用成品）

这是一个安装在本机的物业方案生成工具。页面由本机服务提供，只监听 `127.0.0.1`，不会主动开放到局域网或公网。本机运行不等于完全离线：选用云端或账户引擎时，生成请求会离开这台电脑。

## 1. 如何安装

1. 确认已经安装 Python 3.10 或更高版本。
2. 如需生成 PPT，再安装 Node.js。只生成 Word 可以暂不安装 Node。
3. 双击 `首次安装.cmd`，等待提示“安装完成”。
4. 安装会在程序目录内创建隔离的 Python 环境，不会改你电脑里其他 Python 项目。

## 2. 如何启动

1. 双击 `启动MMF.cmd`。
2. 程序会检查环境、启动本机服务，并打开系统浏览器。
3. 如果使用桌面客户端，双击 `MMF-010.exe`。界面留在程序窗口里，不打开系统浏览器。
4. 不要从带有个人绝对路径的开发目录对外分发。不要把 `runs`、`output`、`providers.local.json` 打进安装包。

源码启动页是：

`http://127.0.0.1:3042/`

## 3. 如何配置AI

第一次打开页面时，先完成“首次配置”：

- 输出目录：点击“选择文件夹”在电脑中挑选，不要手打路径。工作文件和日志由程序自动管理
- 默认 AI 引擎
- 默认输出 Word 或 PPT
- 是否启用本机 Grok Bridge（可选）
- 是否启用 AI 图片服务（千问万相或 Grok Imagine）

然后打开“AI引擎设置”：

- **千问**：填写模型和 API Key，点击“保存配置”，再点“测试连接”。
- **Local Grok Bridge（可选）**：状态分为已安装、需要登录、已连接。只有测试连接通过后才能用于生成。没有 Grok 不影响使用千问。
- **Kimi**：可以填写 API Key，并作为文字模型使用。在 [platform.kimi.com](https://platform.kimi.com) 创建 Key，环境变量为 `MOONSHOT_API_KEY`。国内默认接口是 `https://api.moonshot.cn/v1`，示例模型是 `kimi-k3`。保存后点「测试连接」。Kimi 目前只做文字生成，不能生成图片。
- **智谱 GLM**：同样填写自己的 API Key 后可作为文字模型使用。
- **AI图片服务**：默认使用千问万相，可与文字千问共用同一把 Key；也可改用 Grok Imagine（需要 XAI_API_KEY）。在“AI引擎设置”里保存并测试连接。未配置时不影响文字方案生成。

API Key 默认保存在 Windows 凭证管理器中。页面不回显完整明文，示例配置里也不写真实 Key。这不等于密钥在任何情况下都不会被读到：能使用这台 Windows 账户，或能读取本机凭证的程序，仍可能拿到 Key。请保管好本机账户。

## 4. 如何生成

1. 打开“新建方案”，选择已经连接成功的 AI 引擎。
2. 填写项目名称、业态、场景、输出媒介和需求。
3. 先生成知识推荐，确认后再生成正式初稿。
4. 也可以从招标/需求文件创建，先本地解析，再确认需求。

测试模式（Mock）只验证流程，不能当作正式方案。

## 5. 文件在哪里

生成完成后，页面会显示输出目录。可以直接打开文件夹或复制路径，并用页面上的下载按钮获取 Word / PPT。

默认输出目录在程序文件夹下的 `output`。工作文件和日志由程序自动管理，不需要单独设置。

在「历史记录」中可以：

- 删除历史记录：只从页面列表中去掉这条，已生成的文件仍保留
- 删除历史记录与文件：同时删除这条记录和对应的 Word / PPT 等成品，删除后无法恢复

## 6. 数据会留在哪里

- **本机处理**：程序、页面、招标文件解析和成品文件都在这台电脑上。页面地址是本机回环地址。
- **云端模型**：选择千问、Kimi、智谱 GLM，或登录 Qoder、ZCode、Cursor 时，提示词、必要的招标内容和生成请求会发送到所选服务商。对方如何保存和使用这些内容，以该服务商的规则为准。招标文件、商业秘密和客户资料是否适合提交，由使用者自行判断。
- **Grok Bridge**：这是本机上的桥接程序，不是另一套完全离线模型。它通过本机已登录的 Grok 程序访问 Grok 的在线服务。
- **本地模型**：只有在你另行接入、并且请求不再发往外部服务时，内容才完全留在本机。当前默认引擎都不属于这种离线模型。

## 7. 常见错误

| 页面提示 | 常见原因 | 建议 |
|---|---|---|
| Provider尚未配置 | 还没填写千问密钥，或未测试连接 | 到“AI引擎设置”保存并测试 |
| 网络连接失败 | 无法访问AI服务 | 检查网络后重试 |
| 输出目录不可写 | 选择的文件夹没有写入权限 | 换一个可写目录 |
| 当前Grok Bridge不可用 | 本机没有Grok或未登录 | 改用千问，Grok是可选项 |
| 生成失败，请查看运行日志 | 生成过程出错 | 查看 `logs` 或该次任务目录 |
| PPT相关提示 | 没有安装Node | 可先生成Word，或安装Node后重新运行首次安装 |

本版本是初始可部署版，不是 commercial_ready / production_ready。
