# 开发历程摘要

只保留对外可说的阶段结论。内部 Sprint 原始 JSON、人工验收记录、完整模型调用日志和真实招标不在本仓库。

| 阶段 | 摘要 |
|---|---|
| MMF-001 | 物业方案章节初稿生成器，先打通最小生成链路。 |
| MMF-002 | Provider 抽象与可移植运行时，支持本机安装包形态。 |
| MMF-003 | PPT Renderer v2，Word 之外补上演示稿输出。 |
| MMF-004 | 产品化：本机启动、错误提示、隔离运行。 |
| MMF-005 | 知识选用与承诺治理，减少把未确认数字写成投标承诺。 |
| MMF-006 | 招标长文：需求包、章节计划、篇幅预算、按章生成。 |
| 006D | Word/PPT 版式与治理基线（约 70 页量级 Word / 40 页 PPT 的内部样例）。 |
| 006E | 初始可部署 Alpha：安装、检查点续写、篇幅门禁、多引擎按章写作。 |

当前仓库对应 **v0.1.0-alpha / Initial Deployable**。后续若继续公开，应继续保持密钥与真实客户资料不入库。
